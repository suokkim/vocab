# vocab-strokes

한자 획순 페이지. 날마다 공부하는 한자의 **획순 애니메이션 + 획별 그림**을 한 장으로 만든다.

- 획순 데이터: [KanjiVG](https://github.com/KanjiVG/kanjivg) (CC BY-SA 3.0, Ulrich Apel)
- 페이지는 `YYYY-MM-DD.html` 하나씩. 생성 스크립트는 개인 저장소에 있다.
- 이 저장소는 GitHub Pages 로 서비스된다: https://suokkim.github.io/vocab-strokes/

## 라이선스

페이지에 포함된 획순 경로 데이터는 KanjiVG 에서 온 것으로 **CC BY-SA 3.0** 을 따른다.
